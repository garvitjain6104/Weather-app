I developed a dynamic Weather App that provides real-time meteorological data for any city worldwide. Built using **HTML, CSS, and JavaScript**, the application integrates the **OpenWeatherMap API** to fetch current conditions (temperature, humidity, wind speed) and a 5-day forecast. Key features include automatic user geolocation, error handling for invalid inputs, and a fully responsive **Glassmorphism design** with animated backgrounds to ensure a premium user experience.
